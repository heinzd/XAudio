# XAudio

XAudio is a SwiftUI MP3 player for collections stored in the iOS File System.

## Initial feature set

- Select a root folder with the system file picker.
- Browse its subfolders inside the app.
- Build a playlist recursively from the selected folder, or from the currently displayed folder when no folder is selected.
- Play the fixed playlist sequentially or in a once-shuffled order.
- Navigate backward and forward within that fixed order.
- Read title, artist, album and embedded artwork from MP3 metadata.

## Requirements

- Xcode 26 or newer
- iOS 18 or newer
